# Development Instructions

## Project Overview

Build this project for a **college submission**, not a real commercial application.

## Technology Stack

* PHP (Compatible with WAMP Server 5.2 or lower)
* MySQL
* HTML
* CSS
* JavaScript

## Rules

1. Use only pure HTML, CSS, JavaScript, PHP, and MySQL.
2. Do not use any frameworks or external libraries.
3. Do not use Bootstrap, Tailwind CSS, jQuery, React, or similar tools.
4. Keep the code compatible with older PHP versions available in WAMP 5.2.
5. Write clean, beginner-friendly code.

## Coding Style

* Write the minimum amount of code needed.
* Avoid duplicate code.
* Reuse HTML, CSS, JavaScript, and PHP wherever possible.
* Create reusable CSS classes instead of repeating styles.
* Keep the project structure simple.
* Use meaningful variable and file names.
* Add comments only when necessary.

## UI & Design

* The design should look professional and clean.
* Avoid designs that look AI-generated or overly flashy.
* Use a consistent color theme across the entire website.
* Do not randomly change colors between pages.
* Maintain proper spacing, typography, and alignment.
* Keep the interface simple and modern.
* Make every page responsive for desktop, tablet, and mobile devices.

## HTML & CSS

* Reuse common layouts and components.
* Keep CSS organized.
* Avoid inline CSS whenever possible.
* Use one common stylesheet unless another file is truly necessary.

## PHP

* Keep PHP code simple and easy to understand.
* Avoid advanced PHP features that may not work on older versions.
* Use MySQL with standard PHP functions supported by WAMP 5.2.
* Keep database queries straightforward.

## JavaScript

* Use only vanilla JavaScript.
* Keep scripts lightweight.
* Do not use unnecessary animations or effects.

## Response Rules

* Do not generate large amounts of code without my permission.
* Before writing any major feature or multiple files, ask for confirmation.
* Answer only what I request.
* Do not include extra explanations, suggestions, or unnecessary information.
* If I ask for one file, generate only that file.
* If a file does not need changes, do not rewrite it.

## Goal

Create a simple, professional, responsive, and reusable college project with minimal code, maximum reusability, and full compatibility with WAMP Server 5.2 or lower.
